# Messages and composer

## Compose a message

Messages can contain up to 120,000 characters. If a draft is longer, T3 Code keeps it in the
composer and shows how many characters need to be removed. Shorten the draft or split it into
multiple messages, then send again in the same thread.

## Keep agent messages visible

T3 Code normally collapses intermediate agent messages and tool activity into a work summary after
a turn finishes. To keep agent messages visible, open **Settings**, select **Experimental**, and
enable **Keep agent messages visible**. Tool activity remains collapsed so longer turns stay
scannable.

Mobile preferences are device-local, so enable the setting separately on each mobile device.
